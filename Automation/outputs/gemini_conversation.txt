Requirement:

Custom Furniture E-Commerce Portal Requirements

We are looking to develop a comprehensive online portal to sell our premium custom furniture directly to consumers. The primary objective is to allow customers to browse our catalog, customize furniture dimensions, materials, and colors, and place orders seamlessly.

Core Features
Customers should have access to a rich product catalog with high-quality images and 3D previews if possible. Once an item is selected, they need a configuration wizard to adjust colors, select materials (e.g., leather vs. fabric), and see the price update in real-time. Customers must be able to add these items to a shopping cart and proceed to a checkout page. Payment processing should be handled securely via credit card.

Additionally, there must be an admin backend. Administrators need to log in securely to manage the product catalog, update available materials, and track inventory levels. Admins should also be able to view all past orders, change their fulfillment status, and trigger email notifications to customers.

Technical and Operational Needs
The website must be extremely fast, aiming for a sub-2 second page load time to prevent cart abandonment. It needs to be fully responsive for mobile, tablet, and desktop users. Security is paramount, so the system must comply with PCI standards for handling payments. The application should also be designed to handle traffic spikes smoothly, particularly during holiday sales.

Additional Context
We assume that all users placing an order will be required to create an account so we can track their history and provide customer support. Admins will have a completely separate portal, maybe on a different subdomain. For shipping, we plan to use a flat-rate calculation initially, but we might want to integrate with FedEx or UPS APIs in the future.
